A one-star review written by a house cat about its human — deadpan, specific, and feline to the last word. The human recycled the cat's favourite box. It was the cat's house. The cat is now homeless, and the human still expects purring. One star.

## Run it

```sh
node main.ts
```

This writes the review to `/output/entry.txt` — exactly one line, no trailing newline.
